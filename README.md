# 交替性転向ローバー

ダンゴムシなどが持つ **交替性転向反応**（turn alternation）を、小さな車輪ロボット「ローバー」で再現するブラウザ用シミュレーションです。

交替性転向反応とは、障害物に当たって右に曲がると、次の分かれ道では左に曲がりやすくなる性質のことです。このページでは、その性質があるとどう動きが変わるのかを、目で見て、数字で比べられます。

## 使い方

`index.html` をブラウザで開くだけで動きます。インストールやビルドは不要です。

GitHub Pages を有効にすると、次のような URL で公開できます。

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

## できること

### 1. 障害物のある地形での比較

- **交替ローバー（オレンジ）**：障害物に当たると、前回と逆の向きに曲がります。
- **ランダムローバー（青）**：毎回コイン投げで曲がる向きを決めます。

2台は同じ地形を下の入口から出発し、上端に出たら脱出です。1回終わるごとに新しい地形が作られ、脱出までの平均歩数が記録されます。軌跡には曲がった向き（L / R）が残ります。

### 2. T字迷路の実験

研究でよく使われる装置を再現しています。

1. 通路の途中で、一方へ強制的に曲がらせます（強制転向）。
2. その先の T 字路で、どちらへ曲がるかを記録します。
3. 強制転向と逆を選んだ割合を「交替率」として表示します。

「曲がり角の間の距離」を伸ばすと、交替率が 50%（ランダム）に近づいていく様子を確かめられます。

### 3. 調整できる値

| 項目 | 意味 |
| --- | --- |
| 逆向きに曲がる確率 | 交替ローバーが前回と逆に曲がる確率（50〜100%）。100% で必ず交互、50% でランダムと同じ |
| 記憶が薄れる距離 | 前の曲がり角の影響が弱まっていく距離（マス） |
| 速さ | ローバーが進む速さ（マス/秒） |
| 曲がり角の間の距離 | T字迷路で、強制転向から選択点までの距離（マス） |

## モデルのしくみ

- ローバーは前が空いていればまっすぐ進み、障害物に当たったときだけ曲がります。
- 左右の両方が空いているときは、前回と逆の向きを次の確率で選びます。

  ```
  p = 0.5 + (設定した確率 − 0.5) × exp(−前の曲がり角からの距離 / 記憶が薄れる距離)
  ```

- 片側しか空いていなければ、その向きに曲がります。両側ともふさがっていれば引き返します（このとき、前回の向きの記憶はそのまま残します）。
- 実際のダンゴムシでも交替は「確定」ではなく確率的な傾向です。そのため、初期値は 90% にしています。

### 背景にある考え方

- **方向を保つ**：右と左を交互に繰り返すと、障害物をよけながらも最初の進行方向から大きくずれません。
- **BALM 仮説**（bilaterally asymmetrical leg movements）：曲がるときは外側の脚が多く動くため、次は反対側へ曲がりやすくなる、という説明です。このシミュレーションでは、これを「前回曲がった向きの記憶」として単純化しています。

## ファイル構成
